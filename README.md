# Kaes Mahmud — Portfolio Website

A responsive, static portfolio built with HTML, CSS and vanilla JavaScript. No framework, build step, or backend is required.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `kaes-portfolio`).
2. Upload **all three files**: `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then click **Save**.
6. Wait for the Pages URL to appear in the Pages settings.

## Before publishing
- Replace `hello@kaesmahmud.com` with your actual public email address.
- Check the experience dates and the Agventure entry; a note is visible on the site to flag the current status for confirmation.
- Replace the project case-study links (currently Behance profile links) with the exact project URLs.
- Replace the abstract CSS artwork with your own portrait and real project screenshots if desired.
- Update the stats if the figures on your live Framer website have changed.

## Included sections
Hero, key metrics, selected projects, about, skills, work experience, tools, contact CTA, and social links.
